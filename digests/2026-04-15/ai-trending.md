## 3. Análise de Sinais de Tendência

**Dominação dos Agent Harnesses**: A categoria que mais cresce em atenção são frameworks que estendem LLMs com capacidades agentic — memória, tools, skills e contexto persistente. Projetos como Hermes-agent e Superpowers definem um novo padrão de arquitetura onde o agente não é apenas um modelo, mas um **sistema composicional** que cresce com uso. O sucesso massivo de claude-mem (+2.997 estrelas em um dia) confirma que **memória de longo prazo** é a feature mais demandada para agentes práticos.

**Voicebox como Diferencial**: A emergência de Voicebox como trending representa uma lacuna sendo preenchida — síntese de voz open source de qualidade. Historicamente dominado por APIs proprietárias (ElevenLabs, Azure), o espaço open source agora tem uma alternativa viável, o que sugere uma tendência de **multimodalidade completa** nos stacks agentic.

**Modelos Foundation Verticais**: Kronos introduz um paradigma interessante — modelos pré-treinados especializados emDomínio financeiro. Diferente de fine-tuning tradicional, representa uma arquitetura de foundation model específica, sinalizando que 2026 será o ano dos **modelos Domain-Specific Foundation**.

**MCP como Protocolo Padrão**: Activepieces com 400+ MCP servers indica que o **Model Context Protocol** está se tornando o padrão de facto para tool calling e integração de agentes. Desenvolvedores que adotarem MCP early terão vantagem em interoperabilidade.

**Proliferação de Coding Assistants**: A concentração de projetos focados em Claude Code (skills, memória, best practices) confirma que **coding é a killer app** para agentes — serve como demonstração prática de capacidades agentic para desenvolvedores.
